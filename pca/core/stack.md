# Stack

- React 18
- TypeScript 5.7
- Vite 6
- Lucide React
- CSS propio con tokens y media queries responsive
- Google Fonts: Bricolage Grotesque, DM Sans y DM Mono
- Runtime: Node.js para desarrollo y build
- Deploy objetivo: hosting estático compatible con Vite

## Comandos
- `npm run dev`
- `npm run lint`
- `npm run build`
- `npm run preview`
