# Visual Index

## Dirección
Concepto: editorial AI command center. Fondo papel claro, tinta oscura, acentos amarillo, rosa, verde y azul; bordes rectos, sombras offset y composición de cuaderno/registro.

## Tipografía
- Display: Bricolage Grotesque.
- Lectura: DM Sans.
- Metadatos técnicos: DM Mono.

## Elementos funcionales
- Hero: pila conceptual de idea central, decisiones y próximos pasos; comunica contexto persistente.
- Capítulos: números, etiquetas y líneas editoriales para guiar la lectura.
- Inspección: árbol conceptual del ZIP y estados incluido/beta/servicio adicional.
- Resaltados: fondos y pull quotes para tensiones o conclusiones, no decoración arbitraria.

## Restricciones
No usar imágenes decorativas sin relación semántica ni presentar mockups conceptuales como capturas reales. Revisar responsive en 360, 430 y 1440 px.
