# Active Decisions

- La tesis central es que perder contexto encarece cada regreso a un proyecto; la base ayuda a conservarlo y convertirlo en un punto de partida propio.
- La página debe explicar progresivamente y no parecer una lista de features.
- El producto se comunica con honestidad como base descargable para prototipar y adaptar, no como SaaS terminado.
- Los CTA comerciales deben usar `siteConfig`, especialmente WhatsApp y checkout.
- La dirección visual combina Bricolage Grotesque, DM Sans y DM Mono con fondo papel, tinta y acentos amarillo/rosa/verde/azul.
- No se inventan testimonios, métricas, capturas, garantías ni urgencia comercial.
